# AdvancedSearch

**Group:** Controls  
**Source:** `components/catalog-controls.tsx` (implied from globals.css `.catalog-controls`, `.field`)

Search + filter panel used above catalog grids and archive lists. Keyword input + type/city selects + style tag chips.

## CSS classes

| Class | Role |
|---|---|
| `.catalog-controls` | Filter bar container |
| `.field` | Label + input wrapper |
| `.field__input` | Text input — sharp corners, border on focus |
| `.field__select` | Select dropdown |

## Tokens used

`paper`, `ink`, `ink-muted`, `rule`, `tint-hover` (chip hover), `space-4` (grid gap)
