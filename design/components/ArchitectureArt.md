# ArchitectureArt

**Group:** Display  
**Source:** `app/globals.css` (`.architecture-art`, `.architecture-art--wide`, `.architecture-art--compact`)

Building card component in two variants. Wide: image + metadata side-by-side. Compact: stacked image over metadata. Used within archive rows and feature sections.

## CSS classes

| Class | Role |
|---|---|
| `.architecture-art` | Base card |
| `.architecture-art--wide` | Left image + right metadata layout |
| `.architecture-art--compact` | Stacked image over metadata |

## Tokens used

`paper`, `rule`, `ink`, `ink-muted`, `ink-soft`, `ink-faint` (date), `placeholder` (image bg), `ui-label` (eyebrow)
