# FeaturedCarousel

**Group:** Content  
**Source:** `components/feature-carousel.tsx` (implied from globals.css `.feature-carousel`)

Horizontal carousel of featured building cards. Used on the home page. Prev/next arrows, dot indicators. Maps to `.feature-carousel` and `.archive-row--feature` CSS classes.

## CSS classes

| Class | Role |
|---|---|
| `.feature-carousel` | Carousel container |
| `.archive-row--feature` | Feature variant of archive row |

## Tokens used

`paper`, `rule`, `ink`, `ink-muted`, `placeholder` (image bg), `ui-label` (section eyebrow)
