# BuildingMedia

**Group:** Content  
**Source:** `components/building-media.tsx` (implied from globals.css classes)

Hero image + thumbnail strip + metadata for a single building detail page. Uses `.building-media` and `.building-detail` CSS classes.

## CSS classes

| Class | Role |
|---|---|
| `.building-media` | Hero image container, full-width |
| `.building-detail` | Metadata panel below or beside image |

## Tokens used

`paper`, `ink`, `ink-muted`, `ink-soft`, `rule`, `placeholder` (image bg), `ui-label` style (eyebrow)
